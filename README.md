# 酒縁結び（sake-enmusubi）

その人と、縁のある一本。推しや大切な人を描くと、味ではなく「縁」（名前の一字・ゆかりの土地・生まれた年・今日の気分・蔵の物語）で日本酒を結ぶ、おみくじ型レコメンドです。

- 御縁札をつくる: https://y-kanno-sakenote.github.io/sake-enmusubi/
- 縁の地図（全国の蔵元・銘柄・物語を検索）: https://y-kanno-sakenote.github.io/sake-enmusubi/map.html

## データについて

- 蔵元データ: 日本酒造組合中央会「組合員名簿」を基礎に、各県酒造組合サイト・各蔵公式サイトで突合・補完（全レコード出典URL・確認日つき）
- 座標: 国土地理院 AddressSearch API による住所変換のみ（手入力なし）
- 物語・銘柄・読み仮名: 公式サイト等の一次情報の転記のみ。確認できない項目は「未確認」として保持
- 本サイトは味の好みを診断するものではありません。縁は、飲んでみる理由。
- お問い合わせ: 合同会社サケノテ（sakenote.net）
